The wall

APIs were built for humans.
Machines can't sign up.

A person creates the key, configures it, and hands it to the agent. There is a human in the middle of every machine transaction. Omni402 removes them from both sides: providers sell with one command, agents buy with a wallet.

The mechanism

Payment lives inside the request.

The buyer signs a gasless EIP-3009 authorization. Celo's facilitator submits it on-chain and sponsors the gas. USDC moves buyer to seller inside the token contract. Nobody custodies funds.

01 / ask
Agent calls the API
a plain HTTP request, no key attached
02 / gate
402 Payment Required
the gateway names its price in USDC
03 / sign
Wallet signs, no gas
an EIP-3009 authorization, off-chain
04 / settle
Facilitator pays gas
USDC settles on Celo, receipt returned
